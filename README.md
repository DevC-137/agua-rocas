# Las Rocas | Agua pura

Sitio estático de agua Las Rocas (Huánuco), construido con [Astro](https://astro.build).

## Desarrollo

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

El deploy a GitHub Pages es automático con `.github/workflows/deploy.yml` en cada push a `main`.
